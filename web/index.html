01 Monitoring

A timeline,
not a verdict.

Processes, autostarts, accounts, network activity, sensors and firewall state are observed and joined into one timeline, so every change has a before and an after. What is recorded comes first; what responds to it comes second.

  • Evidence before response
  • Absence is logged as not observed, never as fixed
  • Public threat feeds can only add suspicion, never clear it

Watching is not
the same as trusting.

03 Data protection

Your data stays
where it is.

Argus finds credentials sitting in plain text on the disk and shows you where they are. Its own findings stay on the machine: the dashboard listens only locally and there is no telemetry.

  1. scan passes down through the disk
  2. found SSH keys, tokens and passwords left in plain text, lifted out so you can see them
  3. contained nothing crosses the boundary: no telemetry, findings stay local

Read-only capabilities, systemd units, nothing to configure to start. It audits SSH keys and configuration, sudo rules, systemd units, cron, password-guessing in the auth log, web shells in document roots, container exposure and kernel-level hiding.

Questions

Said plainly, up front.

Does Argus send my data anywhere?

No telemetry. Findings stay on the machine and the dashboard listens only locally. Argus fetches public threat feeds and timestamps, and nothing fetched is ever executed.

Which systems does it run on?

Windows 10 and 11 (64-bit) with WSL2, and Linux servers with systemd.

What does it cost?

Argus Desktop is $79 per year. Argus Server is $50 per server, per year. Pay by card (Stripe) or mobile money (Paypack).

Does it replace endpoint security?

No. It is not a replacement for enterprise endpoint security. Someone with full administrator or kernel control can falsify what any local tool sees, and Argus says so instead of hiding it.

What can it not see?

It compares current attacker techniques with what its own sensors cover and reports the gaps as a work list: argus gaps.
